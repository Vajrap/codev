# Ticket Archive

Completed ticket context lives here.

Use one folder per completed ticket:

```text
codev/tickets/
└── 2026-06-05-example-ticket/
    ├── scope.md
    ├── findings.md
    ├── changes.md
    ├── blockers.md
    └── handoff.md
```

Archive ticket-specific history here, but promote durable project facts into
`codev/knowledges/`, `codev/conventions.md`, `codev/guardrails.md`, or
`codev/glossary.md`.
