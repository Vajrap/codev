# Current Ticket

Use this folder only for the active ticket.

Suggested files:

- `scope.md` — problem, goals, acceptance criteria
- `findings.md` — discoveries made while working
- `changes.md` — files changed and why
- `blockers.md` — open questions or blocked decisions
- `next_steps.md` — handoff for the next session

When the ticket is complete, archive the relevant context under
`codev/tickets/{YYYY-MM-DD-ticket-slug}/`, then reset this folder for the next
active ticket.
