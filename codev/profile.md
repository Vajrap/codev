# Environment Profile

## System Requirements
- OS: macOS / Linux / Windows
- Node.js: >= 18.x
- Package Manager: npm (built-in)

## Setup Commands
1. Clone the repository:
   ```bash
   git clone https://github.com/Vajrap/codev.git
   ```
2. Navigate to the repository:
   ```bash
   cd codev
   ```
3. Link the package locally for development:
   ```bash
   npm link
   ```
   This will install any dependencies (none currently) and create a global symlink for `codev` and `codev-framework`.

## Verification Commands
- Check CLI help:
  ```bash
  codev help
  ```
- Check version:
  ```bash
  codev version
  ```
